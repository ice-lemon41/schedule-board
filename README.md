# 日程看板

一个可以看到**未来 7 天安排**的看板小工具:想到什么先记下来,再拖到某一天。

- 数据全部保存在**你自己的浏览器里**,不需要注册、不需要联网,隐私不外传。
- 电脑和手机浏览器都能用(数据各自独立,不同浏览器之间不共享)。

## 在线使用(最简单)

直接打开:**https://ice-lemon41.github.io/schedule-board/**

不用装任何东西,手机也能用。数据保存在你打开它的那个浏览器里,换浏览器或换设备看到的是各自独立的一份。

## 它能做什么

| 功能 | 怎么用 |
|---|---|
| 看日程 | 页面是一个圆盘:7 个日期标签写在小圆环上(像钟面,**今天在正上方**,顺时针往后);每个日期的事项面板挂在环的外圈,与对应标签对齐;中间的大圆是「待安排」,存放还没定日期的事 |
| 快速记事 | 顶部输入框打字,回车(或点「添加」) |
| 拖拽安排 | 按住卡片拖到想要的日期(或中心圆);同一面板内上下拖可以调顺序 |
| 完成 | 点卡片左边的方框打勾,卡片会变灰但留在原处 |
| 修改 | 点卡片本身,弹出编辑窗口,可以改标题、日期、时间、备注 |
| 删除 | 点卡片右上角的 × |
| 看下周 | 顶部「下一周 →」按钮,整个圆盘换成下一周;「回到今天」随时跳回来 |

> 小提示:事项特别多的时候,每个日期的面板内部会变成可滚动(不会把圆环挤乱);手机等窄屏幕上会自动切换成上下排列的列表,方便阅读。

## 快速录入怎么写

输入框支持用大白话写日期和时间,系统会自动识别。打字时下方会实时预览解析结果,确认无误再回车:

| 你输入 | 系统理解为 |
|---|---|
| `交周报` | 放进当前选中的列(默认「待安排」) |
| `明天 交周报` | 明天 |
| `今天`、`今晚`、`后天`、`大后天` | 对应的日子 |
| `周五 交周报` | 这周五(过了就指下周) |
| `下周一 立项会` | 下周一 |
| `11月20日 体检` | 今年的 11 月 20 日(今年已过则明年) |
| `2027-01-05 返校` | 指定完整日期 |
| `9:30 站会` | 当天 9:30 开始 |
| `15:00-16:30 部门例会` | 带起止时间 |
| `下午3点 导师会面` | 15:00 |
| `晚上8点半 跑步` | 20:30 |

也可以日期和时间一起写,例如 `周五 下午3点 交周报` → 周五 15:00 的「交周报」。

小提示:点一下某列的标题(它会亮起来表示选中),之后不带日期输入的新日程就会落到这一列。

## 本地运行(可选:把代码跑在自己电脑上)

平时直接用上面的在线网址就行;这一节是给想在本地跑代码的人看的。只需要做一次,之后每次照「本地日常使用」两步即可。

### 前提:安装 Node.js

1. 打开 [https://nodejs.org/](https://nodejs.org/)
2. 点页面上绿色大按钮下载(选 **LTS** 版本),下载完一路点「下一步」装好
3. 验证:按 `Win + R`,输入 `cmd` 回车,在黑窗口里输入 `node --version` 回车,显示 `v24.x.x` 之类的版本号就成了

### 安装本项目

1. 下载本项目文件夹(或者克隆:`git clone <仓库地址>`),放在你想放的地方
2. 在项目文件夹的地址栏输入 `cmd` 回车,打开命令行
3. 输入下面的命令并回车(只装一次,大约 1 分钟):

   ```
   npm install
   ```

## 本地日常使用(每次打开看板)

在项目文件夹打开命令行,输入:

```
npm run dev
```

然后**不要关这个窗口**,打开浏览器访问:

**http://localhost:5173**

就能看到你的看板了。用完可以直接关浏览器;那个命令行窗口想关就关,下次要用再开。

## 常见问题

**我的数据存哪了?会不会丢?**
存在当前浏览器的 IndexedDB 里。只要不换浏览器、不清除浏览器数据,关机重启后都还在。注意:换一个浏览器打开(比如从 Edge 换到 Chrome)看到的是空白看板,这是正常的——两边各自独立。清除浏览器浏览数据/网站数据会删掉日程,MVP 阶段还没有导出备份功能(在做的时候会预留)。

**关掉命令行窗口有影响吗?**
`npm run dev` 是本地开发服务器,窗口关了页面就打不开了,但你的数据不受影响。

**手机能用吗?**
直接打开在线网址 https://ice-lemon41.github.io/schedule-board/ 就行。本地运行也可以:手机和电脑连同一个 Wi-Fi,用 `npm run dev -- --host` 启动,再按命令行里提示的地址在手机浏览器打开。两种方式手机里都是独立的一份数据。

**「npm」是什么?**
Node.js 自带的包管理器,负责安装本项目用到的一堆代码库。只用会 `npm install` 和 `npm run dev` 两条命令就够了。
